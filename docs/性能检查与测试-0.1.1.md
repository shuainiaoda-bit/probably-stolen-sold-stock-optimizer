# 已售物品优化 0.1.1：性能检查与测试

测试日期：2026-11-17。游戏版本：1.0.0.15，Steam open_beta Build 26711633。

本次增加全店物品遍历和同步批量操作的刷新合并，保留 0.1.0 的已售仓库优化。

## 已修复的原版开销

1. `EmporiumEntry.GetAllItems`、`GetAllOwnedItems` 和 `PlayerStore.FindAllItem` 的物品树遍历会为库存和物品节点创建子列表。补丁在这些调用点读取原生网格的实际子项，复用本次遍历的队列和去重集合；每次仍返回独立结果，并保留遍历顺序。第三方节点继续使用自身枚举实现。
2. `InventorySortHelper.Commit` 在排列和撤销中逐个重新放入物品，每件物品都可能刷新同一仓库的全部 UI。补丁在同步批量操作中收集待刷新仓库，在操作结束时统一刷新；新增库存与形状变化仍立即更新布局尺寸。原生批量买卖也使用此机制。数据、放置算法和增删事件继续由原版处理，异常退出时通过 finalizer 恢复刷新。

## 验证与范围

库存扩展场景通过 129 项检查，售卖场景通过 79 项检查，两个场景均未捕获运行时错误。检查覆盖查询顺序与所有权过滤、同帧移入移出、返回列表隔离、原生排列与撤销、固定物品、增删事件顺序、回调异常后的刷新恢复、批量买卖、化学品实际反馈、存读档和次日结算。

测试使用真实游戏、Direct3D11、1280×720、隔离桌面后台静音运行。为容纳大批独立物品，临时测试仓库扩大为 180×900，并使用简化背景避免 Unity 图片平铺上限。所有比较保留相同的现有 Mod 组合，诊断宿主的连锁经营功能在两组中均关闭。以上数字衡量指定方法的处理耗时，不能直接换算为玩家画面帧率。结算销毁的整体加速未作为本次收益承诺。

本轮检查还覆盖鼠标命中、工具提示和动画登记路径。原版已有工具提示复用；鼠标命中和动画登记涉及动态 UI 遮挡及生命周期，本次保持其原有行为。

全部测试结束后，真实存档、设置、原生授权和原有 Mod 文件已按哈希恢复。Mod 只维护运行期缓存，不新增存档格式。
