# 已售物品优化 0.1.2：实机加载与共用验证

在游戏 1.0.0.15 测试版中，0.1.2 与另外 10 个已启用 Mod 完成两轮冷启动验证。优化 Mod 分别位于加载顺序首位和末位，每轮 36 项检查全部通过，运行错误为 0。

每轮在独立临时周目售出 2000 件商品，核对收入、已售物品编号和顺序、逐条售卖记录、全店物品查询、原版排列与撤销、智能整理的实际菜单动作、保存及已售物品结算清理。两轮共售出 4000 件商品。实际加载程序集和安装包均为已发布的 0.1.2，DLL 哈希见下文。

## 静音与恢复

每次启动前将游戏四项音量归零，使用 `-noaudio`，并在游戏进程恢复运行前接入系统音频会话监控。两次启动产生的音频会话均确认静音，1417 次目标会话观测的最高输出峰值为 0。其他应用音量写入次数为 0。

游戏运行于独立后台桌面。测试结束后，原存档、原生授权记录、音量设置、全部本地 Mod 文件均按哈希恢复；工坊缓存与测试前一致。

下载 `SoldStockOptimizer-0.1.2.zip`，解压后将 `SoldStockOptimizer` 放入游戏的 `Mods` 目录。在原生 Mod 菜单启用，按游戏提示确认 `reflection-external` 权限后重启。相同 Mod 选择一个来源启用即可。
